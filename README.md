# Anuj Yadav — AI Business Card & Interactive Portfolio

An interactive scrapbook portfolio featuring an AI Assistant trained on **Anuj Yadav's** background, projects, skills, certifications, and experience.

---

## ⚡ Features & Personalization

- **Scrapbook Aesthetic**: Polaroid photo frame, washi tape strips, handwritten stickers, and responsive cards.
- **Interactive AI Representative**: Integrated AI chatbot responding to queries about Anuj's background, AI projects (TDL GPT, Notes-Elitehub, Visual DSA Visualizer), and technical stack.
- **Quick Prompt Pills**: One-click quick question suggestions for visitors.
- **Project Showcase**: Live links to GitHub repositories.

---

## 🛠️ Stack

- **Frontend**: Vanilla HTML5, CSS3 Custom Properties, JavaScript
- **Backend API**: Express.js server / Azure Functions integration
- **AI Engine**: NVIDIA AI / Azure OpenAI / OpenAI API

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start the local server
npm start
```

Open `http://localhost:3000` in your browser.
